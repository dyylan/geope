    geope.units¤

    geope.units ¤

    Physical units for GEOPE: a tag at the boundary, nothing inside.

    GEOPE's numerics are dimensionless. Every optimiser, chart factory and JAX kernel consumes and produces bare floats and arrays, and keeps doing so. This module adds a thin layer around them:

    • A Unit is a name, a dimension and a factor to that dimension's canonical unit. Multiplying a number or array by one builds a Quantity: 25 * ns, 5 * MHz, np.linspace(0, 1, 20) * MHz.
    • A Quantity is a value tagged with a unit. It converts with .to(unit) and does nothing else: no arithmetic, no derived dimensions. It can never reach jitted code — np.asarray(quantity) and jnp.asarray(quantity) raise UnitsError rather than silently absorbing it.
    • A Conversion maps physical quantities to GEOPE's internal dimensionless values and back. Parameters builds one when delta_t is a time quantity and exposes it as params.conversion; it is never constructed by users.

    Two dimensions only. GEOPE writes \(H = \hbar \sum_k c_k G_k\) and \(U_g = \exp(-i\,\Delta T\,H_g/\hbar)\), so the exponent \(\Delta T\,c\) is an angle: \(c\) is an amplitude — an angular frequency, canonical rad/s — and \(\Delta T\) a time, canonical s. An energy \(E\) is the same quantity as the angular frequency \(E/\hbar\), and a cycle frequency \(f\) is \(2\pi f\), so angular-frequency, cycle-frequency and energy units form one equivalence class and convert freely: (1.0 * ueV).to(MHz) is \(E/h = 241.799\) MHz. Hz-family units are cyclic and carry the \(2\pi\); rad/s-family units are angular and carry none; energies carry \(1/\hbar\). A bare float cannot say which was meant; a quantity can.

    The one factor the tag cannot catch is generator normalisation. The Pauli generators are unnormalised (X = [[0, 1], [1, 0]], \(\mathrm{Tr}(G_j G_k) = d\,\delta_{jk}\)), so \(H = \hbar\,c\,X\) rotates the Bloch vector at angular frequency \(2c\): a coefficient of 5 MHz on X is a 10 MHz Rabi frequency, and a \(\pi\) pulse takes \(1/(4 \cdot 5\,\mathrm{MHz}) = 50\) ns. The convention is that the coefficient multiplies \(G_k\) as the basis defines it. A custom basis (projected_basis=) carries whatever normalisation it was built with.

    The scale. With delta_t a quantity, Parameters nondimensionalises with the reference angular frequency \(\omega_0 = 1/\Delta T\), so the internal segment duration is exactly 1.0 and each internal coefficient is the rotation angle per segment — numerically the same problem as the default delta_t = 1.0. The scale is fixed at construction; later delta_t assignments and Gecko subdivision change the internal duration, not the scale.

    Strict when on, invisible when off. With a bare delta_t nothing is checked and no unit objects are built. With a quantity delta_t every physical input must be a quantity of the right dimension, and each misuse raises UnitsError naming the argument. A bare number is always internal; a physical number always carries its unit.

    Raised on any unit misuse.

    Wrong dimension, a bare number where a quantity is required, a quantity while units are off, an unknown unit name, a missing declaration, or a quantity reaching numpy or JAX.

    Quantity ¤

    A value tagged with a unit: a scalar or an array, plus a Unit.

    A tag, not an algebra: to is the only operation. Equality and hashing are disabled because they fail on array values; compare through .to(unit).value.

    A Quantity never crosses into jitted code. Its value is coerced with np.asarray at construction (so one cannot be built from a tracer), and __array__ raises, so np.asarray(quantity) and jnp.asarray(quantity) fail loudly instead of yielding an object array.

    Name Type Description

    The numeric value as a float64 np.ndarray (0-d for scalars).
    unit

    The Unit. May be given by name ("MHz", "rad/ns", "ueV") at construction.

    Conversion ¤

    Per-problem conversion between physical quantities and internal values.

    Built by Parameters when delta_t is a time quantity and read back as params.conversion by Gecko, Geope and Grape. Not constructed by users.

    The scale is held as two Unit objects, so every conversion is a Quantity.to call: this class has no formulas of its own.

    Attributes:

    Name Type Description
    internal_amplitude

    The internal amplitude unit, \(\omega_0\) rad/s with \(\omega_0 = 1/\Delta T\).
    internal_time

    The internal time unit, \(1/\omega_0\) s, so that the internal delta_t is exactly 1.0 at construction.
    time_unit

    Readout unit for times — the unit delta_t was given in.
    amplitude_unit

    Readout unit for amplitudes — the angular partner of time_unit (rad/ns for ns).
    transform_unit

    The unit of param_transform's output, or None.
